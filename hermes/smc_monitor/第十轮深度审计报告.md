## 1. 亏损根因(按证据强度排序)

### R1【最强证据】买点无环境区分: 事件驱动"见事件就买", 无市场条件定价
- 同 rank3 事件: 202606 avg **-3.03%**(n=16) vs 202607 avg **+9.31%**(n=38) — **同强度事件、同参数、同规则, 结果完全反向**
- rank1-7 全期单调性尚可(+0.43→+6.10), 但 202606 内 rank3=-3.03/rank6=-2.98/rank7=-5.06 — **rank 在坏环境里完全失效**
- 202606 是 BULL regime(六态判定全程 BULL) → **亏损不是"弱市"能解释的, 是"牛市里的事件拥挤/题材退潮"**
- 机制: 6 月中旬小盘题材退潮, 事件公告后隔日追买(same-day fill_or_open)直接买在情绪顶, 13/45 笔 hold≤2 即 SL(29%首日止损), 14 笔 MFE>3% 后回落变亏(踏空损失占亏损月 31%)
- **结论: 现在的入场是"无条件买入", 缺一个"此刻该不该买"的 gate** — 这正是 V3 审计 §十三 说的 Entry Quality(第四瓶颈)

### R2【强证据】SL 结构与买点错配: 宽 SL 赚、窄 SL 亏的反直觉分桶
| SL 距离 | n | avg | WR | PF | SL率 |
|---|---|---|---|---|---|
| 窄 <3% | 280 | +0.66 | 34% | 1.47 | 66% |
| 中 3-8% | 459 | +2.00 | 58% | 2.11 | 36% |
| 宽 >8% | 529 | +3.00 | 69% | 2.59 | 19% |
- SL 距离与单笔亏损相关 r=0.32; 窄 SL 组 66% 被 SL 打掉 → **窄 SL 是"假止损"**: 结构位太近, 事件驱动的隔日追买买在波动放大区, 微小回撤就触发
- **窄 SL 的存在本身暴露买点质量差**: 买得离结构位远, SL 才被迫收紧
- TIME_STOP 全期 n=638 avg **+7.54**(WR 79.9%) — **时间退出才是这条腿的主要利润来源**, 证明"事件后动量延续 15bar"是真 edge; SL 只是截断左尾

### R3【中强证据】TP/SL 与真实盈亏分布错配
- TP2_RUNNER n=357 avg +8.61(跑得动的都在跑) — 但 202606 亏损组 mfe 中位 2.2% vs 202607 盈利组 20.3%: **亏损月不是 TP 设置问题, 是行情根本没有给出 TP 空间**(题材退潮期动量不存在)
- 组合推论: R1(无条件买入) + R2(SL 错配) 叠加在无动量月份 → -1.22%/45笔 的亏损月

### R4【工程证据】202606 类月无任何防护
- paper_sim 无 regime/波动状态 gate; WEAK_MARKET_WEIGHT 已因 WF 不稳健被禁用(诚实决定, 但防护位空缺)
- kill switch 只防单日 -3% 连亏, 不识别"月级环境反转"

## 2. 信号稀缺根因(162→20→0 三层分解)
单日(2026-09-10): raw=162 公告 → event_filter_soft 拒 115(71%) → positive=20 → orders=0
- **层1 源头稀缺**: 增持/回购公告本身约 5-9 只/日(历史月均 2025-2027 多为 6-40笔/月, 202504 只有 3 笔, 202412 只有 2 笔) — **公告事件是天然稀缺源**, 与系统无关
- **层2 软过滤吃掉 71%**: event_filter_soft(意愿强度/金额门槛)拒 115/162 — 这是"质量 vs 数量"的主要权衡点; 其中部分被拒事件可能正是 rank2-3 的中强度事件(全期 rank2+3+4=1244 笔占 76%)
- **层3 挂单 0**: 正事件 20 只全部过不了 stage/adx/数据/dup 里的后续门(stage 8/adx 5/nodata 3/dup 7)
- **"近一月无新股"月历确认**: 202507(8)/202508(6)/202512(6)/202605(5) 都是 <10 笔/月的稀缺月; 202504=3, 202412=2 — **稀缺是周期性的, 不是系统坏了**
- 结论: **稀缺 = 源头稀缺(公告供给) × 软过滤(质量取舍) × 结构门(无匹配)**; 单看一天不能优化, 但层 2 的 115 笔被拒事件的前向收益(它们后来涨了吗?)是 V4 必须量化的问题 — 正是 Funnel 丢失候选前向收益要回答的

## 4. V4 迭代方向(六个, 每个含测试方法)

### D1. 环境门(Environment Gate)—— 针对 R1(最高优先级)
- **设计**: 在事件腿选股前加"动量环境分": 用 20D 新高股占比、事件股 cohort 前 5 日平均超额、
  小盘指数(中证1000/微盘)20D 距离三因子合成 E-score。E-score 低 → 降仓/停开新仓(不是拒个股, 是调环境敞口)
- **为什么是"敞口"不是"过滤器"**: 遵守 V3 §十四不加过滤器 — gate 作用在仓位系数, 不杀候选
- **测试方法**: ①202606/202507/202512 三个稀缺或亏损月的事件全重放, 对比 E-score 低位时持仓系数 0.3 的净值曲线;
  ②全期 1640 笔按 E-score 五分位分桶 avg/PF 单调性; ③WFO(12+3月) 检验 E-score 系数稳定性; ④若五分位不单调 → 弃(预注册)

### D2. SL 结构重构(针对 R2)
- **设计**: 废"固定 invalid−1.5ATR"; 改 per-trade 结构化 SL = max(POI 下方结构低点, 1.2×ATR14) 且下限 3%、上限 8%(超出 → 拒开仓, 买太远的信号不接); SL 距离本身作为 entry quality 检验
- **测试方法**: ①461 笔 SL 单全重放: 新旧 SL 的单亏分布/总 PF; ②"SL>8% 拒单"后 n 减多少、avg 变多少(质量换数量量化);
  ③窄 SL(<3%)280 笔在新 SL 下的假止损减少率; ④预注册判定: 新 SL 若 PF 提升但 n 减 >30% → 重新权衡

### D3. 事件-结构融合入场(Replace Pure Event Buy)
- **设计**: 现事件腿"见事件就买" → 改为事件触发 + 结构确认: 事件日若在 DISP/POI 结构附近(±1.5ATR) → 挂 POI 限价; 否则次日开盘买一半仓位(保守模式)。结构引擎(Family DB 已证明 alpha 在后半链)第一次真正接入事件腿
- **测试方法**: ①1640 笔全重放: 纯事件 vs 事件+结构确认 双臂 OOS; ②E4 滑点压力复测(限价单受益于滑点);
  ③若结构确认使 avg 升但 n 减半 → 用 D1 的 E-score 恢复部分无条件敞口(分层: 强环境无条件, 弱环境需结构)

### D4. RECLAIM 简化 + 反转链机理研究(Family DB 延伸)
- **设计**: ①从 run_sequence_v2 正式移除 RECLAIM 层(Family DB 双样本 Δ0.02/-0.35pp 均在线内) → 链提速 ~20%;
  ②E_reverse 机理假设检验: 反转链(先 SHIFT/POI 后 SWEEP)可能是"结构成熟后的流动性回抽确认", 对其加 20/60D 结构距离特征后重跑
- **测试方法**: ①简化链 vs 完整链 6003 笔全对照(应近似相等, 若 |Δ|>0.5pp 则简化作废); ②E_reverse 加特征后 n≥200 重判;
  ③简化后 FSM tests_sequence_v2 全回归

### D5. Profile×Regime×Sequence 参数分布自适应(V3 Phase D 落地)
- **设计**: 不再 if-else 分桶; 对每个 (profile 族, regime 态, sequence 签名) 组合从历史样本学参数分布(贝叶斯/分位数), 如低波动股 → retrace 容忍更深/holding 更长; PANIC → 禁某些 sequence(仅降敞口)
- **测试方法**: ①WFO: IS 学参数分布 → OOS 按 posterior mean 用; ②对照 equal-params 基线, 三窗口 OOS 净值;
  ③预注册: 自适应组若不显著优于 equal(α=0.05, bootstrap) → 保持 equal(诚实纪律, 同 Adaptive WFO 先例)

### D6. 信号源扩展(解稀缺层 1, 工程向)
- **设计**: 增持/回购外扩事件源: ①大股东冻结/质押解除; ②龙虎榜机构专用席位净买; ③定增预案公告;
  ④大宗交易折价率异常。全部走同一 events 分类管线(classify_title_detailed 已就绪)
- **测试方法**: 每个新源先 PAPER 30 日观察(不进生产), 各自跑 rank 分桶单调性; 只有 rank 单调且月均 ≥10 笔的源才保留
- **注意**: 这是"加源"不是"加过滤器" — 与 V3 §十四 不冲突(候选变多是安全的, 变少才危险)

### 通用验证纪律(全部迭代适用)
回测→OOS→SHADOW→PAPER 四级留痕; 预注册判定线先写后跑; 荒谬数字不解释只找根因;
生产 EVENT 基线(n=1640/+3.72/PF3.45)与 registry 每次提交 MD5 校验; 每迭代全量回归 435+ PASS。

## D1 的核心洞察（写回蓝图）
事件腿的真 alpha = **事件质量(rank) × 环境质量(E)** 的乘积项——rank 单调但无环境识别（R1），E 无 rank 信息但完美分离环境。两者正交 → 融合应显著优于任一单因子。这是 D3（事件-结构融合）之外的第二条融合路径：**rank×E 双因子矩阵**。

## D1B rank×E 双因子矩阵（融合路径证据）
815 笔可配对（E 需当日全市场新高占比，覆盖 50%）：
- **黄金象限（rank≥3 & E∈Q4/Q5）**: avg **+5.95** / WR **73.7%** / n=243 —— 全局 +3.08 的近两倍
- **杀单区（rank≤2 或 E∈Q1）**: avg +1.07 / WR 52.3% / n=329（占 40%）—— 仍为正但远弱
- 最好格 r5_Q5（+15.99）vs 最差格 r6_Q1（−9.50）: spread **25.5pp**，预注册①通过
- **诚实判定**：②杀单区负贡献、③黄金格超全局一倍 —— 均未达（杀单区非负）→ **E 的正确用法是排序/仓位（弱 E 降仓），不是杀单**。与 V3 §十四"不加过滤器"纪律完全自洽。
