# SMC V14 — 每股参数优化引擎

## 核心改进
- 入场点一次检测 -> 10组SL/TP快速模拟 (比V12快5-10x)
- 每股独立最优SL/TP参数
- 摆动点入场确认
- 信号质量评分 (量/K线/gap/摆动点/趋势)

## V18 每股参数优化 — 整合V16 Swing策略

### 测试结果 (2026-05-08, 50只)

**19/50只可优化股票**(V16策略下, 其余无交易或不足2笔)

| 指标 | V14 (旧) | V18 (新, Swing集成) | 提升 |
|------|---------|-------------------|------|
| 样本 | 200只 | 50只 | — |
| 可优化 | 70 | 19 | — |
| 平均WR | 68.2% | **82.7%** | **+14.5%** |
| 最优SL | 0.3% (87.6%) | **0.3% (100%)** | 一致 |
| 最优TP | 5.0% (87.5%) | **3.0% (95%)** | 收紧 |
| SL分布 | 0.3%/0.5% | **100% 0.3%** | 更一致 |
| seq过滤 | 无 | **100% 0.0 (无过滤)** | 新维度 |

### V18 核心改进

1. **Swing SL集成**: 只有当摆动SL可用时才用摆动点(20K线内), 否则固定SL=0.3%+FVG-only跳过OB
2. **参数空间**: SL=[0.3%, 0.5%, 0.7%], TP=[3.0%, 5.0%, 8.0%], seq_filter=[0.0, 0.3, 0.5]
3. **评分函数**: `WR × sqrt(N) × min(PF, 20) / 100`
4. **平均优化后WR=82.7%** (vs V16统一WR=76.9%)

### 优化结论(最新的)

1. **SL=0.3%最优**(与V14一致): 摆动SL封顶0.5%提供自然保护, 固定SL只需0.3%防假突破
2. **TP=3.0%最优**(与V14的5.0%不同): 结合紧SL, 3.0%TP提供RR=10x, 更快兑现
3. **seq_filter=0.0**(无过滤)：信号序列过滤对已筛选的交易帮助有限, 更适合作风险控制维度
4. **每股优化价值**: WR从76.9%→82.7%(+5.8%), 值得在实战中使用

### 已知陷阱

1. 只有V16策略下可交易(>=2笔)的股票才能优化。约60%股票因无信号或无交易被跳过
2. 优化偏向过拟合: 89%的优化结果选择SL=0.3%/TP=3.0%/seqF=0.0, 可能在更大样本上泛化不佳
3. 建议: 优化后需在独立验证集上测试(未来N根K线)
