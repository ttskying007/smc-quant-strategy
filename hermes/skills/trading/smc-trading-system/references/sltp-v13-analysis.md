# V13 TP/SL设计分析与优化方向

## 当前设计

```python
SL = cost_line * (1 - atr_pct * 1.2)     # 成本线下方ATR×1.2
TP1 = entry_price * (1 + atr_pct * 2.0)  # 2×ATR
TP2 = entry_price * (1 + atr_pct * 4.0)  # 4×ATR
Trailing = 3×ATR激活, 0.8×ATR trail距离
```

## 实际统计 (1,399笔)

| 指标 | 值 |
|------|-----|
| SL均值 | 8.62% |
| SL中位 | 7.92% |
| SL范围 | 1.47~36.72% |
| TP1命中 | 96% |
| TP2命中 | 36% |
| RR均值 | 1.43x |
| RR中位 | 1.41x |

## SL对RR的影响

| SL区间 | 笔数 | WR | PnL | RR |
|--------|------|-----|------|-----|
| SL<5% | 247 | 93% | +6.40% | 1.71x |
| SL5-8% | 468 | **99%** | +10.68% | 1.64x |
| SL>8% | 684 | 98% | +13.51% | 1.19x |

**核心发现**: SL>8%时RR降至1.19x — SL过宽直接吞噬RR。
优化: SL应cap在max(ATR%×2, 3%)与min(8%, cost_line×0.97)之间。

## 持仓对RR的影响

| 持仓 | 笔数 | WR | PnL | RR |
|------|------|-----|------|-----|
| ≤5bar | 864 | 97% | +11.27% | 1.49x |
| 5-15bar | 364 | 99% | +12.49% | 1.47x |
| >15bar | 171 | 94% | +8.96% | 1.05x |

**核心发现**: >15bar交易RR仅1.05x — 应提前30bar time_stop或收紧trailing。
