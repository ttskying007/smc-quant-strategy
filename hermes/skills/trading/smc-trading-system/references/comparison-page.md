# 版本对比分析页 (/compare)

## 数据源
- `/tmp/build_comparison.py` 从各版本JSON生成 `/root/.hermes/smc_opt_v16/comparison.json`
- 聚合 V16.2/V16.1/V16/V15/V13/V12 所有交易数据

## 页面内容
1. **版本演进对比表**: 按WR排序, 显示交易数/股票数/WR/均盈/RR/TP1/TP2/累计PnL/出场分布
2. **上下文影响力**: 每个版本的ctx_score→WR映射, 颜色编码(≥80%绿, ≥60%黄)
3. **当前选股对比**: 引擎分布, Top5, 回测覆盖比例

## 颜色编码规则
- WR ≥90%: 绿色 #3fb950
- WR 80-90%: 橙色 #d29922
- WR <80%: 红色 #f85149
- RR ≥2.0: 绿色
- RR 1.5-2.0: 橙色
- RR <1.5: 红色

## 关键发现 (来自对比页)
- V13 WR=97.3%最高但RR=1.31x最低 — 高胜率但盈亏比不理想
- V16 avg=+13.12%最高且RR=3.46x最高 — 单笔收益最优但WR=74.5%最低
- V16.2 最佳平衡: WR=89%, RR=2.08x, avg=+10.72%
- V12 7960笔最多但WR=81.8% avg=+6.53% — 数量牺牲质量

## 更新方法
```bash
cd /root/.hermes/scripts && python3 /tmp/build_comparison.py
```
每次重新回测后运行, 对比页自动更新。
