# 趋势过滤 — 下跌中的OB_Bull是假信号

## 发现 (2026-05-15)

**症状**: V22回测10,545笔交易覆盖4,517只股票，180只当前活跃信号。用户质疑在大盘下跌时不应该有这么多买入信号。

**诊断**: 采样100只近期信号, 32%在明确的下跌趋势中:
- 688455.SH: 20日趋势 -27.6%, 距60日高 -29.7% → 严重下跌中触发OB_Bull买入
- 600382.SH: 20日趋势 -13.6%, market_state=trending_down → 下跌中触发

**根因**: OB_Bull是纯结构性信号 — 只要摆动低点处有阳线, CHOCH/BOS突破就触发。不检查股票自身趋势方向。在下跌趋势中, 这些"看涨OB"只是下跌中的反弹(bear market rally), 不是真正的买入信号。

## 修复 (V12引擎)

```python
# 新增趋势过滤 — 放在OB入场之前
if state == 'trending_down':
    continue  # 拒绝下跌趋势

ma20 = sum(closes[max(0,ob.idx-20):ob.idx])/min(20, ob.idx)
if closes[ob.idx] < ma20:
    continue  # close必须在MA20上方

high60 = max(closes[max(0,ob.idx-60):ob.idx+1])
drawdown = (closes[ob.idx]-high60)/high60*100
if drawdown < -20:
    continue  # 距60日高不超过20%
```

同时选股从1,791(60bar历史) → 180(5bar当前+趋势过滤)。

## 核心教训

1. **结构性信号 ≠ 方向性信号**: OB_Bull告诉你"这里有聪明钱活动", 但不说方向
2. **趋势上下文决定信号有效性**: 下跌中OB_Bull=假信号, 无论有多少SMC上下文
3. **选股数多≠信号好**: 4,517→180是信号质量提升, 不是损失
4. **大盘环境最重要**: 指数下跌时绝大多数个股OB_Bull都是假信号
5. **不要信任纯结构的backtest**: 历史回测覆盖了牛市和熊市, WR被牛市信号拉高
