# V20.11: Bar-Level Multi-Timeframe Alignment (d7)

## Overview

The final missing piece of multi-timeframe resonance: verifying that the daily Order Block's price zone overlaps with a weekly demand/support area. This creates "multi-timeframe confluence" — the most powerful SMC setup where both daily and weekly charts agree.

## Implementation

Added `MTFResonance.check_daily_ob_weekly_alignment()` in `/tmp/v17_engine.py`.

### Scoring (0-4 points, threshold ≥2)

1. **Weekly demand zone alignment (+2/+1)**:
   - Daily OB center price within 5% of weekly swing low (recent 5 bars) → +2
   - Daily OB low above weekly support but within 3% → +1

2. **Price above weekly MA20 (+1)**:
   - Basic bullish alignment check

3. **No weekly breakdown (+1)**:
   - Recent weekly range < 1.5× average range → controlled, not breaking down

### Integration

Called in V19 engine after `check_weekly`:
```python
mtf_align_ok, mtf_align_score = MTFResonance.check_daily_ob_weekly_alignment(
    weekly, dz_low, dz_high, ob_idx
) if weekly is not None else (False, 0)
```

Alignment bonus added to `mtf_result['total_score']` when `mtf_align_ok=True`.

## Data Coverage Limitation

Only 191/4905 (3.9%) stocks have weekly data. For stocks without weekly data, this check is skipped (no penalty).
