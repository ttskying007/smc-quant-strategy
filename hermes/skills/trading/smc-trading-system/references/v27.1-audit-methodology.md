# V27.1 全量审计方法论 (2026-05-20)

## 审计原则

**不要做理论风险审计。做代码级逐行审计。** 
区分"确定问题"、"高风险待验证"、"过度推断"三个等级。
必须先跑数据，再下结论。

## 7项核心审计点

| # | 审计点 | 检查方法 | 验收标准 |
|---|--------|---------|---------|
| 1 | BOS/CHOCH 是否 confirmed swing + state machine | 检查trend状态机、swing确认逻辑 | confirm_idx ≤ event_idx |
| 2 | MSS 是否 sweep + CHOCH + displacement | 检查has_sweep_precursor字段 | 100%有sweep前置 |
| 3 | OB 是否 anchor 到结构事件 | 检查anchor_event_idx字段 | 0缺失 |
| 4 | OTE 是否 impulse 不扫未来 | 断言impulse_end ≤ event_idx | 0未来函数 |
| 5 | BPR 是否 opposing FVG overlap | 检查fvg1/fvg2方向相反 | 0同向FVG |
| 6 | SWEEP 是否 confirmed swing + reclaim | 检查swept_swing_idx + close回收 | - |
| 7 | 回测/选股/K线/复盘是否同源 | 检查ver_map、reload_trades/picks | 单一event ledger |

## 审计脚本模式

```python
# 全量加载
trades = json.loads(TRADES_PATH.read_text())
picks = json.loads(PICKS_PATH.read_text())

# Anchor审计
ob_no_anchor = [t for t in trades if not t.get('zone',{}).get('anchor_event_idx')]
bpr_same_dir = [t for t in bprs if fvg1_dir == fvg2_dir]

# 时间顺序审计
bad_order = [t for t in trades if t['entry_index'] <= t['signal_index']]
zone_after = [t for t in trades if t['zone_idx'] > t['entry_idx']]

# 未来函数审计
non_causal = [t for t in trades if not t.get('audit',{}).get('causal')]
```
