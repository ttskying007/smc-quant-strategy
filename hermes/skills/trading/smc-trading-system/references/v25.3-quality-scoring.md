# V25.3 Signal Quality Scoring System

## Four Dimensions (each 0-10, combined 0-40)

### Z — Zone Quality
Base scores by zone type:
| Zone Type | Score |
|-----------|-------|
| BreakerBlock_Bull/Bear | 7 |
| IFVG_Bull/Bear | 6 |
| FVG_Bull/Bear | 5 |
| OB_Bull/Bear | 4 |
| BPR | 4 |
| LiquidityVoid | 3 |
| OTE_* (standalone) | 3 |
| Rejection_* (standalone) | 3 |

Age adjustments:
- ≤5 bars: +0 (fresh expected, not bonus)
- 6-10: +0
- 11-20: -1 (aged)
- >20: -2 (stale)

Confirmation bonuses:
- IDM_BOUNCE: +1
- PB_BOUNCE: +0
- REV_BOUNCE: -1 (weakest)

### S — Signal Sequence
Base: 5
- Sweep present: +2 (or -1 if missing)
- CHOCH present: +2 (or -1 if missing; BOS=+1)
- MSS present: +1
- Retrace/OTE present: +1
- Pinbar at zone: +1
- LiquidityVoid fill: +1
- EQL/EQH: +1
- Breaker in sequence: +1
- IFVG in sequence: +1
- Length ≥5: +1 (or -1 if ≤2)
- Rejection at zone: +1

### C — Confirmation Quality
Base scores:
- BREAKER_ENTRY: 7
- SWEEP_ENTRY: 6
- IDM_BOUNCE: 6
- PB_BOUNCE: 5
- PINBAR_ENTRY: 5
- OTE_ENTRY: 5
- CHOCH_ENTRY: 5
- BOS_ENTRY: 5
- REV_BOUNCE: 4
- ZONE_RETRACE: 4
- default: 4

Bonuses from signal sequence:
- OTE in sequence: +1
- Pinbar in sequence: +1
- LV in sequence: +1
- Sweep in sequence: +1

### M — Multi-Timeframe Resonance
Regime-based proxy (real MTF uses weekly/60min data):
- TREND_UP/DOWN: 5
- WEAK_UP/DOWN: 3
- RANGE: 1

## New Entry Confirmation Types (V25.3)

signals_v22.py does NOT produce IDM_BOUNCE/PB_BOUNCE signal types.
The V25 scan derives confirmation from signal sequence context:

```python
recent_types = [s.type for s in zone_sigs[-3:]]
if any('Sweep' in t for t in recent_types):
    conf_type = 'SWEEP_ENTRY'
elif any('Pinbar' in t for t in recent_types):
    conf_type = 'PINBAR_ENTRY'
elif any('OTE' in t for t in recent_types):
    conf_type = 'OTE_ENTRY'
elif any('CHOCH' in t for t in recent_types):
    conf_type = 'CHOCH_ENTRY'
elif any('BOS' in t for t in recent_types):
    conf_type = 'BOS_ENTRY'
elif any('Breaker' in t for t in recent_types):
    conf_type = 'BREAKER_ENTRY'
else:
    conf_type = 'ZONE_RETRACE'
```
