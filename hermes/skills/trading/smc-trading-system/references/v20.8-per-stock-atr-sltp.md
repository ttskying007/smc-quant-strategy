# V20.8 Per-Stock ATR Dynamic SL/TP

## Motivation

V20.7及之前使用regime固定%: 所有同regime股票共用同一套SL/TP参数。但ATR范围1.2%~16.1% — 高波动股(ATR=8%)和低波动股(ATR=1.5%)用同样的SL会被反复震出或止损过宽。

## 实现位置

`/tmp/v17_engine.py` → `SmartMoneySLTP.setup_for_atr()` (V20.8重写)
`/tmp/v19_engine.py` → regime_params override跳过逻辑

## setup_for_atr V20.8

```python
def setup_for_atr(self, atr_pct: float):
    if atr_pct > 5.0:      # 极高波动 → 窄倍数(等比例缩小)
        self.tp_tiers = [atr_pct*0.015, atr_pct*0.025, atr_pct*0.04, atr_pct*0.06]
    elif atr_pct > 3.0:    # 高波动
        self.tp_tiers = [atr_pct*0.015, atr_pct*0.025, atr_pct*0.04, atr_pct*0.06]
    elif atr_pct > 1.5:    # 正常 → TP1约2%ATR, TP4约7%ATR
        self.tp_tiers = [atr_pct*0.02, atr_pct*0.03, atr_pct*0.05, atr_pct*0.07]
    else:                  # 低波动 → 宽倍数(等比例放大)
        self.tp_tiers = [atr_pct*0.025, atr_pct*0.04, atr_pct*0.06, atr_pct*0.09]
    
    self.sl_atr_mult = 1.2  # SL = cost_line × (1 - atr_pct × 1.2)
    self.trail_distance_pct = max(0.01, min(0.04, atr_pct * 0.01))
```

## SMC核心: SL基于成本线

```python
adj_pct = sl_initial_pct * quality_sl_mult * volatility_sl_mult
```

## ⚠️ regime_params覆盖陷阱

`setup_for_atr()`设置per-stock值后, regime_params循环会用固定值覆盖:

```python
# ❌ BAD: 覆盖per-stock动态值
for k, v in regime_params.items():
    if hasattr(sltp, k): setattr(sltp, k, v)

# ✅ GOOD: 跳过ATR已计算的字段
for k, v in regime_params.items():
    if k in ('tp_tiers', 'sl_initial_pct'): continue
    if hasattr(sltp, k): setattr(sltp, k, v)
```
