## TurtleSoup Detection

```python
# Uses sw_dict['highs'] and sw_dict['lows'] with bar_idx field
for sw in swing_lows:
    sw_idx = sw.get('bar_idx', 0)
    for j in range(sw_idx + 1, min(sw_idx + 4, n)):
        if lows[j] < sw_price and closes[j] > sw_price * 1.01:
            # Bullish TurtleSoup: false break below support → reversal
```

**Key debugging lessons**:
1. `sw_dict` uses keys `highs`/`lows` (NOT `swing_highs`/`swing_lows`)
2. Bar index field is `bar_idx` (NOT `bar` or `idx`)
3. A-share daily charts rarely produce TurtleSoup patterns — swing levels are structural and rarely get false-broken
4. Detection threshold relaxed from 2% to 1% reversal confirmation without effect — pattern is genuinely rare
