## RR自校验脚本

```python
import json
t = json.load(open('/root/.hermes/smc_opt_v19/v19_i1.json'))
for tr in t:
    sl = tr.get('sl_initial', 0)
    tp_str = tr.get('tp_tiers', '')
    if not tp_str: continue
    tp1 = float(tp_str.split(',')[0].replace('%', ''))
    if tp1 > 0 and sl > 0 and tp1 / sl < 1.0:
        print(f'RR异常: {tr["symbol"]} SL={sl}% TP1={tp1}% RR={tp1/sl:.2f}x')
```
