# Market Hours Detection & Smart Pause

## A-Share Trading Hours
- Mon-Fri, 9:30-11:30 CST, 13:00-15:00 CST
- All other times (nights, weekends, lunch break 11:30-13:00): market closed

## Server-Side Detection

```python
import datetime

now = datetime.datetime.now(datetime.timezone(datetime.timedelta(hours=8)))
weekday = now.weekday()  # 0=Mon..6=Sun
t = now.hour * 60 + now.minute
market_open = weekday < 5 and ((570 <= t < 690) or (780 <= t < 900))
```

## API Response
`/api/live-prices` returns `market_open: true|false`. When false:
- Server skips Hubble API call entirely (saves resources)
- Server returns `error: '休市 (交易时间: 周一至周五 9:30-11:30, 13:00-15:00)'`

## Client-Side Pause

```javascript
let refreshTimer = null;
let marketOpen = false;

// On loadPrices response:
marketOpen = data.market_open || false;
if (!marketOpen) {
    document.getElementById('countdown').textContent = '已暂停';
    document.getElementById('refresh-btn').style.display = 'none';
    if (refreshTimer) { clearInterval(refreshTimer); refreshTimer = null; }
} else {
    document.getElementById('refresh-btn').style.display = '';
    if (!refreshTimer) {
        refreshTimer = setInterval(updateCountdown, 1000);
    }
}
```

## Resource Savings
- ~18 hours of market-closed time per day
- 265 stocks × 30s polling = ~530 API calls/hour saved
- ~9500 API calls/day saved (not polled during closed hours)
- Hubble API quota preserved for actual trading hours
