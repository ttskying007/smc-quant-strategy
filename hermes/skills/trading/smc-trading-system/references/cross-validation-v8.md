# V8.x 全量交叉验证结果

## 方法

V8.0 (窗口法): 5个时间窗口×8种信号类型, 3331只股票
V8.1 (全量法): 全300-bar+H1/H2前后半段+Bull/Bear市场状态, 4905只股票

## 结论

**当前16个月数据不支持per-stock信号切换。** OB_Bull是唯一统计显著的通用信号。

### V8.0 每窗口最优
所有5个季度窗口(2025Q1-Q4, 2026Q1)最优信号均为OB_Bull:
OB_Bull: WR 95-100%, avgPnL +12.97%→+16.43% (改善趋势 ↗)

### V8.1 全量
200只有效分析中100%以OB_Bull为最优。非OB信号每只股票n=0-2次/16月。
放宽gap阈值+Sweep_BSL后: 27只非OB(12.3%), 仍n=2, 无统计显著性。

### 信号时间趋势
- OB_Bull: ↗改善 (+12.97%→+16.43%)
- BOS_Bull→FVG_Bull: ↗↗大幅改善 (+2.08%→+8.63%, 4倍!)
- Sweep_SSL→FVG_Bull: ↘衰减 (+4.77%→+3.11%)
- Sweep_SSL→Pinbar_Bull: ↘↘加速衰减 (+3.61%→+0.39%)

### 市场状态差异
OB_Bull在Bull(+15.02%)和Bear(+14.72%)均有效, 差异仅0.3%。

## 监控策略

基于此结论:
1. 主力: OB_Bull (全部股票)
2. 辅助加分: BOS→FVG (趋势改善)
3. 降权: Sweep系列 (衰减中)
4. 半年后重新评估非OB信号统计显著性
