# V20.3 Live Monitoring — AJAX架构

## 演进

| 版本 | 刷新方式 | 问题 |
|------|---------|------|
| V20.3初版 | `<meta http-equiv="refresh" content="30">` | 用户反馈"整个页面全部刷新", 白屏闪烁, 体验差 |
| V20.3终版 | JS `setInterval(loadPrices, 30000)` + 倒计时 | AJAX局部刷新, 仅更新表格, 无闪烁 |

## 最终架构

```
页面加载 → loadPrices() 首次fetch → 渲染表格
         → setInterval(updateCountdown, 1000) 每秒倒计时
         → 倒计时归零 → loadPrices() 再次fetch → 仅更新#live-table DIV
         → 循环...
         → 手动按🔄按钮 → 立即loadPrices() + 重置倒计时
```

## 关键代码

```javascript
let secondsLeft = 30;
function updateCountdown() {
    document.getElementById('countdown').textContent = secondsLeft + 's后刷新';
    if (secondsLeft <= 0) { loadPrices(); secondsLeft = 30; }
    else { secondsLeft--; }
}
setInterval(updateCountdown, 1000);
```

## 用户反馈

- "优化一下，现在是整个页面全部刷新" → 用户明确要求局部刷新
- 换成AJAX后不再问第二遍 → 满足需求

## 增强功能

- **更新时间显示**: `更新: 09:53:07 (2.0s)` — 含API耗时
- **倒计时**: `18s后刷新` — 用户知道下次刷新时间
- **手动刷新按钮**: `🔄 刷新` — 立即触发, 重置倒计时
- **声音警报**: SL/TP命中时播放base64 WAV提示音
- **顶部徽章**: `[3 SL] [2 TP]` 实时告警数量

## 注意

- JS中不要用模板字符串`${}`因为Python f-string会冲突 → 用字符串拼接`+`
- `currentPrice > 0` 判断是否交易时段 → 非交易时段显示"休市"
- Hubble API非交易时段返回空数据 → `error_msg`提示用户
