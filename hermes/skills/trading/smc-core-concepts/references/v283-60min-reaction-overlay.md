# V283 60min 前日反应覆盖审计教训

## 触发场景

V282 证明真实行业参与度能提升日线分层时间语法，但大样本年度最低 WR 仍只有 45%-48%，小样本口袋跨年断裂。下一步验证：在 V280 日线候选买入日前一交易日，60min 级别是否已经出现接管/吸收反应，可否剔除后续 SL。

## 审计范围

- 脚本：`/root/.hermes/scripts/v25/v283_60min_reaction_overlay_audit.py`
- 产物：`/root/.hermes/smc_audit/v283_60min_reaction_overlay_no_write_20260702_212216/`
- 最新摘要：`/root/.hermes/smc_audit/v283_60min_reaction_overlay_latest.json`
- 输入：V280 全量 82,400 个日线分层语法事件。
- 60min 数据：4553 个缓存文件，因每股约 500 根 60min，仅覆盖近端窗口，最终可覆盖 17,294 个候选。
- 防未来函数：只使用 entry_date 前一交易日的 60min 日内特征；不使用买入日盘中/收盘数据。
- 生产/前端/watchlist 写入：全部 false。

## 测试特征

- `RET`：买入日前一交易日 60min 合成日内收益。
- `POS`：前日收盘在日内高低区间的位置。
- `MSS`：前日最后收盘是否突破前两根 60min 高点。
- `L2`：前日最后两根 60min 是否均为阳线。

## 核心结果

| 条件 | n | WR | Avg | 年份 | 说明 |
|---|---:|---:|---:|---|---|
| `ABSORB_SSL_FAST_MSS + DOWN + RET0~1 + POS>=60 + MSSY + L2Y` | 100 | 56.00% | +1.03% | 2025/2026 | 最优大样本但远低生产 |
| `REV_SSL_CHOCH_OB + DOWN + RET0~1 + POS35~60 + MSSN + L2N` | 21 | 66.67% | +1.33% | 2025/2026 | 样本太小 |
| `UP_CONT_BOS_OB + RANGE + RET0~1 + POS35~60 + MSSN + L2N` | 25 | 60.00% | +2.42% | 2025/2026 | 样本太小 |

## 结论

1. **当前 60min 缓存只能做近端验证**：覆盖 17,294 / 82,400 个事件，主要是 2025/2026，不能作为全市场多年定论。
2. **简单 60min 反应特征不够**：前日 60min 收强、MSS、最后两根阳线等简单特征只能把最优大样本推到 56%WR，仍不能解释日线语法失效。
3. **剩余问题不是“是否有60min上涨反应”，而是反应语义太粗**：必须检测 60min 内部的 sweep→reclaim→micro-HL/MSS→回踩不破，而不是用日内收益/收盘位置替代 SMC 结构。
4. **V280/V282/V283 合并结论**：机会数量已经充足；日线时间顺序 + 前日市场/行业 + 粗 60min 反应均不能生产。下一步不是继续加桶，而是构造真正的 60min SMC 子结构确认器，或补全历史 60min 后做同源多周期生成。

## 使用注意

- V283 是 no-write 研究审计，不得接生产。
- 60min 简单收益/位置/MSS 只能作为诊断字段，不能作为生产门禁。
- 后续若做 V284，应实现 60min 内部结构序列：前日/确认日 `SSL sweep -> reclaim -> micro BOS/MSS -> HL retest`，并与日线 zone 对齐。
