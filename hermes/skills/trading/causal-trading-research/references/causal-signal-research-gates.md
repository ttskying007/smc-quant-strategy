# 可审计 SMC 研究门禁：冻结回放与失败归因

## 1. 先定义什么算“可用”

在生成 seeds 前固定一组硬门槛。例如：

- 总样本 ≥ 1,000；每个检验年度 ≥ 300；
- A 股 T+1 违规 = 0；
- 胜率 ≥ 55%；平均净收益 ≥ 0.50%；PF ≥ 1.15；payoff ≥ 0.70；
- 每个年度平均净收益均 > 0。

这些是研究门槛，不是可在看完结果后调节的优化参数。样本仍须明确标注数据覆盖范围；部分历史范围通过也不等于生产可用。

## 2. 冻结 replay 约定

回放必须在结果打开前冻结：

- entry：信号后的下一根可交易 bar/open；
- stop：只来自当时已知的结构失效位置；
- target：只选 entry 前已确认、未被后续价格消耗的结构流动性目标；
- 退出：严格从下一交易日第一根 bar 起；
- 同一根 bar 同时触及：SL-first；
- 费用、最大持仓 bars、同标的串行仓位规则均固定。

对滚动缓存，储存的 index 会漂移。回放时用不可变 `symbol + trading timestamp` 重绑定，不能把旧 index 直接解释成新事件。

## 3. 性能模式：不要用每个 seed 扫完全部历史 pivot

结构 target 的朴素做法会对每个 seed 重扫大量 pivots 与历史区间，容易超时。可采用：

1. 对每个 symbol 预计算已确认 swing highs；
2. 按时间向前维护 active、尚未被价格穿越的 target 池；
3. pivot 仅在其 right-side confirmation 后进入池；价格首次触及/穿越则永久移除；
4. 对每个 entry 用二分检索满足最小计划 RR 的最近价格 target；
5. 用小样本暴力枚举逐 identity 对比缓存算法，确认 identity 完全一致后再跑全量。

这只优化计算，不改变信号或回放本体。

## 4. 失败归因模板

若冻结对象失败，至少给出：

- 按 SL、GAP_SL、TP、TIME exit 的笔数、胜率和净收益；
- MFE ≥ 1R、MFE ≥ 目标、MAE ≤ -1R 比例；
- 风险距离、目标距离、计划 RR、年份、入场时段、因果间隔的分布；
- 标的集中度。只有足够样本的面板才可描述，不可用极小标的分组得出规则。

把“获利分桶”视为诊断线索，不是生产过滤器。新假设必须解释失败机制，并回到结果盲 seed 阶段。

## 5. 价格链失效后，成交量研究的正确形态

纯价格序列可能形式完整但缺乏主动资金参与。一个可反驳的替代假设可以是：

1. sweep 在前 20 根成交量分布的高分位；
2. BOS 的实体和成交量同时高于事先固定的局部基准；
3. FVG 是同一位移的一部分，宽度和成交量同样合格；
4. 首次 FVG 回踩/收回发生在相对缩量，表示供给衰竭或吸收；
5. 下一根未观察 bar 才可成为 entry。

注意：分位数、倍数、窗口、最多等待 bars 必须是打开新收益之前固定的机制参数；不可由失败对象的结果切片反推。
