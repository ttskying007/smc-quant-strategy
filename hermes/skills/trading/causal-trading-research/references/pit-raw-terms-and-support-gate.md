# PIT 原文事实、时点与支持门禁

适用于公告正文、公司行动条款或披露时点构成**独立因果信息**的新研究；不适用于把旧标题事件或旧 OHLCV 过滤器换名后重跑。

## 固定顺序

1. **冻结元数据分母**：按不可变 `announcement_id` 去重。正股/债券等同公告证券别名只保留 provenance，不能扩大分母。
2. **原文逐条验收**：payload `art_code` 等于 metadata ID；payload 时间与 metadata 发布时间精确一致；正文非空并保存 SHA-256。内嵌正文为空时，只允许同 ID、同发布时间的官方 PDF 附件恢复，不得跨公告补写。
3. **覆盖审计**：总量与逐年都必须 100%。代理/连接瞬时失败应重试并显式记录，不能记作“没有公告”。
4. **价格源资格也逐事件验收**：缓存第一根 bar 必须不晚于由 `publication_time` 推导的 `observation_start`，且其后有合同要求的足量 bars。仅检查“该 symbol 有后续 bar”不能证明事件响应可观察；rolling cache 可能在事件之后才开始。
5. **正文语义**：bounded-section parser 与独立 regex/parser 必须给出相同 canonical identity，才可预注册价格本体。
6. **结果盲 seed → 独立 Oracle**：Oracle 必须重建 identity、节点日期、POI/zone、时序和去重；它的一致性只证明实现一致，不能替代样本支持。
7. **支持失败立即关闭**：若 seeds 未达预注册的总量、逐年或标的门槛，则不执行 replay/scanner/生产；不得靠扩张窗口、改变结构、RR、止损、目标、年份、缓存或过滤器变体挽救。

## 公司行动条款层

标题/metadata 只是候选索引，不能充当条款事实。可在原文覆盖通过后单独资格化的字段包括：每十股现金分红、送转/转增、分配基数、回购/注销数量、解禁数量与可转债条款。正文源未完成前，不得定义价格本体或将标题事件当成这些字段的替代。

### 标题定位 pilot 与全覆盖的边界

- 标题可用于**运输/字段可得性 pilot**：定位公告 ID 后，逐条验证 `announcement_id == payload.art_code`、发布时间与 `eitime` 精确到秒一致、正文非空；再测量原始短语/数值单位能否提取。
- 这类 pilot 即使全部候选正文可恢复，也只证明官方正文 transport 与字段提取能力，**不能**证明全市场条款分母完整；标题搜索不能代替完整正文归档或可证明穷尽的官方全文检索。
- 对正文端点的瞬时连接失败，应对同一官方端点、同一公告 ID重试后重新做身份/时间/正文验证，并报告初始失败、恢复、未恢复。恢复成功应记为 transport recovery，不得记为公告缺失；未恢复则保留为覆盖缺口。
- 只有单独预注册并通过全宇宙正文覆盖、发布时间与身份审计后，才允许建立正文语义目录；在此之前禁止 seed、价格数据、SMC 本体、回放或生产。

## 关闭类型

- **源资格失败**：正文/身份/发布时间/可观察时点不完整 → 关闭数据对象。
- **语义失败**：独立解析器不一致 → 关闭语义对象。
- **支持失败**：结果盲 seeds 不足 → 关闭该本体，不读 outcomes。
- **Oracle 失败**：独立重演不一致 → 关闭该本体，不做 replay。
- **经济失败**：单次冻结严格 T+1 replay 未过门槛 → 关闭该本体，不能调参重开。
