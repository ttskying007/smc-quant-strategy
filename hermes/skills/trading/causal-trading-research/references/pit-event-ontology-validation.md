# PIT 公告事件本体：验证与关闭模式

## 适用场景

当纯价格/成交量 SMC 本体已被冻结回放关闭，但仍有可用的、带精确披露日期和发布时间的公告元数据时，可研究一个**新的 PIT 信息维度**。公告不是用于事后筛股，而是前置因果条件；公告后仍须由已确认的价格结构完成入场链。

## 必须先完成的事件目录

1. 对固定历史范围逐日或逐证券抓取公告元数据；保留 `symbol`、公告 ID、公告日、发布时间、标题和命中术语。
2. 记录预期覆盖量、已完成量、失败量、分页完整性及时间戳完整性。
3. 目录阶段不得读取市场价格、成交量、seed、交易或收益文件。
4. 在预注册中冻结标题纳入/排除规则、证券范围和事件去重键；不能在看见表现后更改词表。

## 合格的新本体模板

`PIT_EVENT -> 后续确认结构突破 -> 突破前固定 Demand OB -> 首次回踩并收回 -> 下一交易日开盘`

- 公告日不能是响应或买入日。
- 高点/低点只在右侧确认完成后才可使用。
- POI 必须在回踩前固定；entry 必须晚于公告、结构确认和 reclaim。
- 先生成 outcome-blind seeds，再用独立实现从原始公告和 OHLC 重建 `(symbol, planned_entry_date)` identity 集合；只有 exact match 才能做一次冻结回放。

## 一次冻结回放的硬合同

冻结：次日开盘 entry、结构 SL、仅使用入场前已确认且未消耗的结构 TP（计划 RR >= 1.5）、费用、T+1 退出、保守 SL-first 同日碰撞规则、最长持仓和同标的串行仓位。不得为回放失败的本体再调窗口、标题词表、SL/TP、持仓、年份、标的或阈值。

## 已验证的反例（用于避免重复研究）

2023–2025 全市场利润分配预案/方案公告维度采用：

`PIT_PROFIT_DISTRIBUTION_PLAN -> 3L/3R 确认 BSL 接受 -> Demand OB 回踩收回 -> 次日开盘`

- 结果盲 seeds：9,134（2023: 1,497；2024: 3,183；2025: 4,454；3,865 标的）
- 独立 Oracle：9,134/9,134 exact match
- 严格 T+1 冻结回放：7,240 笔；时间顺序、预入场 RR、执行合同偏差和 T+1 违规均为 0
- 结果：WR 33.3564%，AvgNet +0.0760%，PF 1.0249；2023 -2.0675%、2024 -0.5843%、2025 +0.7748%
- 结论：支持与时序完整，但经济门槛失败；**关闭这一“利润分配公告 + BSL/Demand retest”本体**，不得对其做 selector、词表、时窗、止损、目标、持仓、日历或标的切片变体。

这说明：高样本、精确 PIT 与零 T+1 违规只能证明研究无泄漏，不能替代跨年经济性。下一条研究必须采用不同的、日期可寻址的 PIT 机制，而不是从这个失败本体中挑选表现好的切片。
