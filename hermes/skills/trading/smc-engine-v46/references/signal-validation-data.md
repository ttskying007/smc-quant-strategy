# A股日线SMC信号验证数据 (2026-05-15全量)

## 验证方法论

- 数据: 4,905只A股，24个月日线
- 回测: T+1可执行，无未来函数
- 标准: WR>80%为可用，WR 60-80%为需过滤，WR<60%为不可靠
- 历史版本: V9(全信号)→V10.2(SMC上下文过滤)→V11(高级SMC+自适应)

## 关键验证教训

1. **不要假设西方市场SMC概念在A股也有效** — FVG、Mitigation、CHOCH都需要本地验证
2. **信号数量 ≠ 信号质量** — V9的17,008笔只有64.1% WR vs V10.2的1,839笔有84.2%
3. **日线远比60min可靠** — A股60min噪声大，日线结构更清晰
4. **OB是第一且最可靠的信号** — 几乎所有SMC流派都从OB出发，数据证实了这一点
5. **Per-Stock参数差异真实但有限** — 4档市场状态可覆盖90%场景
