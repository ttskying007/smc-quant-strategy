# V8 真实案例: 300097.SZ 逐Bar追踪 (2026-05-15)

## 概述

从V477全量2124笔中选择300097.SZ（智云股份）Trade 1做逐bar追踪，展示SL/Trailing的真实运作机制。

## 交易概况

```
Symbol: 300097.SZ
Trade: OB_Bull, 60min
Entry: bar[116] 2026-04-07 10:30  @ 7.68
Exit:  bar[141] 2026-04-15 11:30  @ 9.55 (trailing)
PnL: +24.35%  |  SL: 0.26%  |  Hold: 25 bars  |  RR: 93.0
TP: swing_high @ 10.80 (+40.63%) — 从未接近
```

## Bar-by-Bar 追踪

```
Entry: bar[116] @ 7.68  SL=7.66 (entry*0.9974, 仅0.26%下方!)

--- 死区开始 ---
[117] O=7.72 H=8.16 L=7.71 C=7.90  ext=8.16 gain=+6.25%  SL=7.66 (不动!)
[118] O=7.92 H=7.94 L=7.85 C=7.88  ext=8.16 gain=+6.25%  SL=7.66
[119] O=7.88 H=7.97 L=7.86 C=7.86  ext=8.16 gain=+6.25%  SL=7.66
... (bars 120-139 全部SL不动) ...
[139] O=8.33 H=8.38 L=8.32 C=8.37  ext=8.38 gain=+9.11%  SL=7.66

--- Trailing激活 ---
[140] O=8.36 H=8.63 L=8.35 C=8.58  ext=8.63 gain=+12.37% SL=8.20 ↑
                                     (extreme*0.95, gain>=10%)
[141] O=8.58 H=10.04 L=8.51 C=10.04 ext=10.04 gain=+30.73% SL=9.04 ↑
                                     (extreme*0.90, gain>=20%)
       low=8.51 < SL=9.04 → EXIT @ 9.04
```

## 发现

### 1. SL死区

bars 117-139（24根bar, ~6个交易日）SL完全不动。价格从7.68涨到8.38(+9%)，SL仍停在7.66。

根因: V477 loose profile中gain>=5%档位收紧到`entry*0.985=7.56`，小于初始SL=7.66。`max(7.66, 7.56) = 7.66` — 收紧完全无效。

### 2. Trail激活后立刻退出

bar[140]激活trailing(SL跳到8.20)，bar[141] extreme冲到10.04后回落到8.51，触发退出。trailing只有1根bar的"有效期"。

### 3. TP完全装饰

TP=10.80(+40.63%)。价格最高到10.04(+30.73%)时trailing已触发退出。TP从未被触及。

### 4. 初始SL无结构意义

SL=7.66 = entry*0.9974。与300097的OB区域、ATR、摆动点没有任何关系。纯`atr*0.09`的数学结果（被0.15%下限钳制）。

## V8修复后行为

V8将SL下限从0.15%改为0.30%，trailing档位从`entry*0.985`改为`entry*1.01`（lock 1% profit）。同一笔交易在V8下的行为:

```
Entry: bar[116] @ 7.68  SL=7.66 (V8: entry*0.997=7.66, 0.30% floor)

[117] gain=+6.25% → gain>=5%: SL = entry*1.01 = 7.76 (lock 1%)
[140] gain=+12.37% → gain>=8%: SL = extreme*0.96 = 8.28
[141] gain=+30.73% → gain>=18%: SL = extreme*0.92 = 9.24
       low=8.51 < SL=9.24 → EXIT @ 9.24 (vs V477's 9.04)
```

V8的退出价9.24高于V477的9.04，因为trailing在gain>=5%时就开始lock利润，且SL随extreme增长更平滑。
