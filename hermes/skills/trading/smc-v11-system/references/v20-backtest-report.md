## 序列统计

- 有序列的股票: 2,658 / 4,800 (55%)
- 总序列数: 3,907
- 序列 → 交易转化率: 759 / 3,907 = 19%
  - 仅 1/5 的序列末端 FVG/OB 满足入场条件

## 结论

**序列过滤不提升交易质量。** 原因:
1. 当前序列模式筛选掉的交易和保留的交易质量相同 (WR差0.6pp)
2. 71%交易在1 bar内完成 (T+1次日即止盈)，信号前置对次日结果影响有限
3. 序列→交易转化率仅19% — 大部分序列末端信号不在入场范围内

**建议**: 不将序列作为入场过滤器。Baseline (FVG_Bull + OB_Bull + 结构TP/SL) WR=72.7%, PF=3.9, 累计+29,948% 为可用基线。

取而代之，使用 **自由组合上下文评分** (见 `references/v20-free-combo-mining.md`)。
