# V500 纯结构TP/SL回测 (2026-05-12)

## 动机

用户要求用纯SMC结构做止盈止损回测 — 不用任何固定百分比或ATR自适应。

TP: 入场后前方所有结构阻力位 (swing_high / OB.upper / FVG.upper / CHOCH/BOS突破位 / BSL)
SL: 入场处最近的结构支撑位 (swing_low / OB.lower / FVG.lower / SSL)

TP必须 > entry + 1%, SL必须 < entry。

## 无结构SL悖论

4,757笔(12%)入场下方无任何结构支撑。但这些交易**WR=67.5%**高于有结构SL(62.4%)。

原因: 无支撑=强趋势中，支撑位在远处，-8% fallback反而够宽，不会被假突破止损。

## 关键结论

1. **TP充足**: 11.2个候选/笔，65%在TP1-3命中。结构TP设计有效。
2. **SL偏弱**: 入场不在支撑位上。需要4%+距离才可靠。
3. **根因是入场精度**：收盘价入场而非支撑位入场。修复方向=ENTRY_AT_ZONE模式（在FVG.lower/OB.lower入场）。
4. **紧SL需要精确结构匹配**: 0-1%距离的支撑不可靠。如果要在支撑位入场，SL可设在支撑下方0.3-0.5%。
