# V20 自由组合挖掘 — 数据驱动发现有效信号组合

2026-05-13

## 动机

V20 序列检测使用 22 种固定模式 (Sweep→CHOCH→FVG→OB 等)，但回测显示序列过滤不提升交易质量 (WR 72.1% vs baseline 72.7%，交易减少95%)。

用户提出"自由组合"思路：不做预定义模式，从真实交易数据反向挖掘哪些信号组合有效。

## 方法

对 V20.1 Baseline 回测的 14,196 笔交易，向前追溯 5 bar 内出现的所有信号类型，统计每种组合的胜率和盈亏比。

脚本: `scripts/free_combo_mining.py`

## 关键发现

### 1. 单个信号在入场前的效果排名

**OB_Bull 是王者信号**：出现频繁且 WR 最高。看跌信号 (BOS_Bear, MSS_Bear, CHOCH_Bear) 出现在入场前 → 高 WR，代表趋势反转确认。

### 3. TOP 自由组合 (数据挖掘，非预定义)

所有高 WR 组合的共同特征：**看跌上下文 + OB_Bull 入场**。

## 核心规律

**OB_Bull + 看跌上下文 = 高胜率反转交易。**

经典 SMC 序列 (Sweep→CHOCH→FVG→OB) 不是数据中最优的模式。实际最优模式更简洁：
- 入场前有看跌信号 (BOS_Bear/MSS_Bear/Sweep_BSL) → 下降趋势确认
- OB_Bull 在结构点出现 → 趋势反转入场
- BPR 和 EQL 作为额外确认增强 WR

## 应用建议

与其使用固定序列模式过滤入场，不如用**信号上下文评分**：
1. OB_Bull 入场前 5bar 内出现 BOS_Bear/MSS_Bear/CHOCH_Bear → +15% weight
2. EQL 出现 → 流动性区域确认 → +10%
3. BPR 出现 → 多区域共振 → +5%
4. 信号密度 4-6 个 → +10%

总分 > 阈值 → 入场。这比二元序列匹配更灵活且数据支持更强。
