# ICT 4个高胜率交易模型 — A股日线适配分析

## 模型一：标准反转 (SH + MSS + RTO)
**适配**: 推荐实施 ✓
- SH猎杀止损: 当前Sweep检测已覆盖
- MSS位置约束: V11.3新增 (必须在流动性上方/下方)
- RTO回撤FVG/OB: V36已在FVG入场
- A股日线评估: 可交易股票数会减少但WR有望提升至88-90%

## 模型二：一击必中 (Breaker + FVG)
**适配**: 部分实施 ✓
- Breaker Block: V11已有检测
- Breaker + FVG重叠: V11.3新增 (has_fvg_overlap标记)
- A股日线评估: 信号质量极高但数量很少, 适合作为次级策略

## 模型三：超级模型 (Breaker + OB + FVG)
**适配**: 不建议 ✗
- 日线三重重叠频率极低(可能每周0-1个), 交易机会太少
- 逻辑保留但不作为主策略

## 模型四：AMD (Accumulation + Manipulation + Distribution)
**适配**: 不适用 ✗
- 这是日内模型(亚盘→欧盘→美盘), 完全不适合A股日线

## 综合量化约束

1. **时间过滤**: 不适用A股日线(日线只有一根K线, 没有亚盘/欧盘区分)
2. **双重流动性消化**: 代码未实现(需要跨周期跟踪)
3. **FVG选择逻辑**: 选择最靠近SSL的FVG — 代码未实现具体逻辑但方向正确
4. **MSS位置约束**: V11.3已实现
5. **FVG与OB重叠**: 代码已有, 通过序列分析(sequencer_v11.py)中的家族映射处理

## 空白点 (未实现)

- Double Purge (同方向连续两次流动性猎杀后反转)
- FVG选择逻辑: 如果有连续FVG, 选最靠近流动性池的那个
- 多周期对齐: 日线+60min的SH→MSS→RTO完整链
