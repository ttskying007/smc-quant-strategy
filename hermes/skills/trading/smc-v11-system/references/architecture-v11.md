# SMC V11 — 架构蓝图与设计原理

## 为什么需要V11而不是继续V8.4/V10

### V8.4的局限

V8.4通过300轮×40股票的全局优化达到了WR=80% (R13), 但:
1. **全局参数意味着妥协**: 茅台(ATR~1.2%)和中芯(ATR~4%)用同一套SL/TP
2. **单日线无法精确入场**: 日线信号得到后, 4H/1H/15min的精确入场完全缺失
3. **无API保护**: 全量扫描5,400只股票时, 大批量请求触发HTTP 429
4. **信号顺序未被利用**: Sweep后才出现的FVG vs 先出现FVG再Sweep, 后者质量差很多

### V10的局限

V10创新了共振+序列框架, 但:
1. **无时间约束**: 信号间的K线距离没有上限, 几十K线前的CHOCH也算在序列里
2. **无自适应**: 仍然依赖全局种子参数
3. **单TF检测**: 在日线上检测所有TF的信号, 而不是真正获取4H/1H数据
4. **完整的V10从未在真实数据上验证过**: 框架写好了但没跑全量回测

### V11的设计原理

1. **参数个性化 > 参数优化**: 每只股票基于自身ATR%计算参数, 而不是从全局找最佳
2. **时间约束 = 信号质量**: 信号间距越小, 越可能是同一波动的连续动作
3. **多周期 > 单周期**: 真实的多TF数据比模拟对齐可靠得多
4. **限流保护 > 无限调用**: 免费API需要保守使用, 3 req/s + 3并发是最佳平衡
5. **自适应 > 搜索**: ATR%和波动率分类可以直接推导出合理参数, 不需要300轮搜索

## V11 四维共振公式

```
resonance_total = tf_score × 0.30 + indicator_score × 0.30 + swing_score × 0.25 + temporal_score × 0.15
```

### 各维度的设计理由

**TF共振权重最高(30%)**: 经验表明, 日线和4H方向一致时, 胜率显著高于方向冲突时。
一只股票如果日线↑、4H↑、1H↑, 做多的胜率天然比任何指标都高。

**指标共振(30%)**: FVG+Sweep+OB+CHOCH四重同步出现在同一个价格区域,
比单一信号可靠得多。但四个指标全对齐的情况很少(~5%的交易日),
所以权重略低于第一反应应该调用的TF共振。

**摆动共振(25%)**: Micro/Meso/Macro摆动点对齐提供了结构确认,
但不是所有股票都形成清晰的摆动点结构(尤其是ETF和指数)。

**时间共振(15%)**: 信号间距离是辅助维度的理由是——好信号本身就密集,
时间分只是确认"这确实是好信号"。

## 序列匹配的时间窗口

为什么必须用时间窗口约束:

```
Good:   Sweep@idx=10 ---[2bars]--- CHOCH@idx=12 ---[3bars]--- FVG@idx=15
Bad:    Sweep@idx=10 ---[40bars]-- CHOCH@idx=50 ---[25bars]-- FVG@idx=75
```

第二个序列虽然信号类型匹配, 但40根的间隔意味着这很可能是两次独立的市场事件,
而不是一个连续的机构行为。V10会错误地将两者都标记为Gold序列, V11通过时间窗口
(8/12/10)自动排除第二种情况。

## 自适应参数推导

```
1. 计算ATR% (14日)
2. ATR% < 1.5% → low volatility → SL=ATR×0.5, sweep_wick=4.0
3. ATR% 1.5-3.5% → medium → SL=ATR×0.6, sweep_wick=3.0
4. ATR% > 3.5% → high → SL=ATR×0.7, sweep_wick=2.5
5. TP = SL × 2.5 (固定盈亏比目标)
6. fvg_min_width = ATR% / 200 (自适应FVG敏感度)
7. 应用阶段修正 × 周期修正
```

## V11.2 实际测试结果 (vs 预期)

| 指标 | V11设计预期 | V11.2实际(200股) |
|------|------------|------------------|
| 整体WR | 65-75% | 50.0% |
| 选股后WR | 75-85% | 70% (29/119) |
| 平均RR | 2.0-3.0x | 5.03x |
| 信号密度 | 8-15/100bars | ~10/100bars |

**差距分析**: WR低于预期主要是因为:
1. Scout序列(43%交易)噪音大(~45%WR) — 单FVG/OB信号不够可靠
2. 多周期缺失 — 仅有日线, 无4H/1H共振确认
3. 现有序列模式仅检测Sweep→CHOCH→FVG→OB四种, 还有更多有效模式
4. 部分股票在300日窗口内无趋势, 信号随机

**超预期项**: RR=5.03x远高于2-3x预期, 因为最优参数倾向于SL=0.5%/TP=5.0%(RR=10x理论值), 实际~5x说明一半交易被SL击中。
