# V11.2 最优参数参考

来源: rolling_backtest_v3.py 参数扫描 (5 SL x 4 TP = 20组合)
每只股票选出 `WR^2 * sqrt(N) * min(3, PF) * min(2.5, RR)` 最高的参数组合。

## 通用默认值
- SL: 0.5%
- TP: 5.0%
- 适用于 91% 的可交易股票

## 模式

```
SL=0.5% + TP=5.0%   → 高RR(5-13x), WR 40-92%  — 最稳健
SL=0.5% + TP=2.0%   → 低RR(~2x), WR 25-75%   — 适合波动小的股票
SL=1.0% + TP=5.0%   → 低WR(7-43%), RR~3x     — 宽松止损表现差
```

紧SL+宽TP组合 > 宽SL+紧TP组合。A股日线波动大, 紧止损+宽止盈是最优策略。
