## Bear TP bug修复方案

### 旧代码 (V38.0-V38.3)

```python
# Bear方向TP检测 (错误的, 方向无关)
if tp_price and extreme <= tp_price * 1.10:
    sl = min(sl, entry_price * (1 - max(0.8, tp_pct * 0.5) / 100))
    if extreme <= tp_price * 0.98:
        return j, tp_price, True
```

问题: `tp_price * 0.98` — 对bear来说tp_price在入场下方, 0.98使价格需要额外过冲2%。对0.5%的micro swing (最常见), 实际需要从入场下行2.5%才能触发 — 5倍目标距离。

### 新代码 (V38.4)

```python
# Bear方向TP检测 (方向感知)
if tp_price and extreme <= tp_price * 1.05:  # tep: 10%->5%, 更贴近target
    sl = min(sl, entry_price * (1 - max(0.8, tp_pct * 0.5) / 100))
    if extreme <= tp_price * 1.02:  # FIX: 1.02替代0.98
        return j, tp_price, True
```

对称逻辑:
- Bull: `extreme >= tp_price * 0.98` (达到目标98%即触发, 从下方接近)
- Bear: `extreme <= tp_price * 1.02` (达到目标102%即触发, 从上方接近)

## 设计原则

1. **方向感知的乘数**: trailing和TP检测中的乘数因子必须根据方向适配。固定乘数(如0.98)在不同方向产生截然不同的效果。

2. **无结构TP = 噪声**: 没有结构TP目标的交易(无法找到清晰的swing_high/swing_low)WR极低(27-37%), 应使用最紧的trailing快速逃逸。

3. **3- профиль > 单一阈值**: 不同场景需要不同的trailing策略。最优场景(有TP)+方向差异可以显著提升RR。

4. **A股bear方向有根本劣势**: 市场长期上行漂移使bear做空天生比bull做多难。需要专门优化, 不能简单对称处理。

5. **200只测试缩放可靠**: 全量4800结果与200只测试偏差<7%。200只测试(~30s/轮)作为开发迭代的筛选工具, 方法论验证有效。
