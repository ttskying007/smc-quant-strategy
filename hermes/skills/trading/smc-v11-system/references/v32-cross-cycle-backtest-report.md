## 结论

1. **日线 >> 60min**: 94% vs 69%, 60min不值得独立使用
2. **bullish+S→D = 94.8%** WR, 三窗口极稳定, 最优策略
3. **bearish只做L→D** (86.8%), S→D样本太少(N=125)
4. **做空全部无效** (WR<50%), A股T+1限制
5. **周线趋势有效**: bullish过滤提升WR ~2pp vs neutral
6. **跨周期模式不一致**: 仅32%, 需分别选股
