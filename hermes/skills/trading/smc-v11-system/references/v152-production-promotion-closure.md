# V152 production promotion closure pattern

Use this when a research/backtest SMC variant has passed gates and needs to become the current dashboard/API contract without contaminating current picks.

## Rule

Promote historical/backtest contracts as **trades/report artifacts**, not as live buy candidates.

- Historical production rows: used by `/api/summary`, backtest tables, K-line overlays, and audit reports.
- Live/current picks: must remain sourced from the full-market daily scanner or equivalent current-market generator.
- Historical rows must carry `pick_scope=HISTORICAL_BEST` and `is_active_pick=false` unless they were generated by the current full-market scanner.

## Artifact shape

For a promoted version `Vxxx`, write:

- `smc_opt_vxxx_<contract>/vxxx_report.json`
- `smc_opt_vxxx_<contract>/vxxx_trades.json`
- `smc_opt_vxxx_<contract>/vxxx_trades.csv`
- `smc_opt_vxxx_<contract>/vxxx_picks.json` — empty if no current candidates
- `smc_opt_vxxx_<contract>/vxxx_active_picks.json` — empty if no current candidates

Report gates should include:

- source release gate pass
- sample threshold pass, e.g. `n >= 120`
- WR threshold pass when applicable
- avg PnL within allowed baseline delta
- `t1_zero`
- `field_missing_zero`
- `no_live_historical_picks`

## smc_unified.py routing checklist

Add the version directory to promoted routing with minimal edits:

1. define `Vxxx_DIR`
2. `_promoted_contract_dir()` returns `(Vxxx_DIR, 'vxxx')` first when its report exists
3. `_promoted_trade_file()` returns `vxxx_trades.json`
4. `reload_metrics()` returns `vxxx_report.json`
5. `_active_pick_mtime()` includes `vxxx_active_picks.json` if cache invalidation should notice pick changes

Do not change the daily scanner merge functions merely to force historical trades into active picks.

## Verification gate

Before claiming completion, run real endpoint checks:

- `/api/summary` shows promoted version/engine/count/WR/avg PnL
- `/api/picks/contract` confirms no historical rows became tradable active picks
- `/api/picks` still returns current/watch rows from the live-pick pipeline
- `/api/live-prices` still responds
- `/api/reload` works after the serving process is stable
- `/api/kline_full?symbol=<known_promoted_trade>&tf=daily&ver=V88` returns the promoted engine trade overlay with zone/cost-line fields
- frontend root contains the promoted version label and headline metrics
- port/PID check confirms the intended `smc_unified.py` process is serving port 8890

## Pitfalls

- If a background restart fails with `Address already in use`, do not assume the new code is serving. Check PID/port and verify `/api/summary` returns the promoted version.
- A single transient `/api/reload` disconnect during restart is not the lesson. Repeat after the process is stable.
- Git/index tooling failures during release verification should be reported separately, but they do not replace endpoint and artifact gates.
