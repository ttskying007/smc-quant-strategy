# 公告事件本体预注册（Lane A/B，标题级）

> 状态：PREREGISTRATION_FROZEN（数据拉取完成后执行）
> 数据：东财公告（标题 + 类别列），2023-2026 全市场（拉取中，已完成 158/750 天）

## 1. 目标

在 TP2-R20（多头动量，2026 崩塌期失效）之外，寻找**独立于市场 regime 的事件驱动 alpha**，组合后补足 2026 年。

## 2. 事件定义（标题级，PIT 可用）

| 事件 | 标题关键词 | 类别（column_name）| 预期逻辑 |
|---|---|---|---|
| **A1 业绩预增/扭亏** | 业绩预告/预增/扭亏/大幅增长 | 业绩预告 | 基本面改善 → 公告后资金流入（聪明钱确认）|
| **A2 业绩预减/首亏** | 预减/预亏/首亏 | 业绩预告 | 利空出尽？或回避 |
| **B1 回购** | 回购/股份回购 | 回购 | 公司自认为低估 → 支撑 |
| **B2 增持** | 增持/控股股东增持 | 股东增持 | 大股东信心 |
| **B3 减持** | 减持/拟减持 | 股东减持 | 压力（回避）|
| **B4 解禁** | 限售股上市流通/解禁 | 限售解禁 | 供给压力（回避）|

## 3. 事件研究设计（PIT 严格）

- **事件日**：公告披露日（notice_date）
- **PIT**：披露日收盘后可得 → 披露日次日（T+1）开盘可决策
- **窗口**：事件后 T+1 ~ T+5 的开盘/收盘收益（观察期），或事件后首个 SMC 信号（事件 → SMC 确认 → 入场）
- **对照**：无事件股票同期表现（基线）

## 4. 与 SMC 主轴组合（信号组合方向）

```
公告事件（A1/B1/B2 利好类）发生
  → 事件后 N 日内出现 SMC 三周期信号（TP2-R20）
  → 事件确认 + 结构确认 → 入场
（或）事件本身作为独立信号源，单独回测
```

## 5. 门槛（与 TP2-R20 相同）

- 每年 WR≥55%、AvgNet≥+0.5%、payoff≥0.70（2024/2025/2026）
- 全市场（非精选）、T+1=0、outcome-free
- 组合后：每年 avg 相对 TP2-R20 基线提升（尤其 2026 年）

## 6. 判定

- 事件驱动单独或组合后使 **2026 年转正或显著减亏** → 质变达成
- 事件无增量 → 如实记录，继续其它方向
