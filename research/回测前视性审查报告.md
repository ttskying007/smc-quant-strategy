# 回测方法前视性（未来函数）审查报告

> 日期：2026-08-18 | 目的：诚实验证组合策略回测是否含未来函数/前置信息

---

## 一、逐环节审查结论

### 1. SMC 三周期信号（TP2-R20）— ✅ 无未来

| 环节 | 使用的数据 | 是否有未来 |
|---|---|---|
| 摆动点（3/3 确认）| 只用左侧+右侧确认 K 线（确认完成才可见）| ✅ 无 |
| 周线权限 W1 | 严格早于当前周的周线结构 | ✅ 无 |
| SSL sweep / reclaim | sweep 日及之前 | ✅ 无 |
| POI（OB）| 事件后、入场前的 K 线 | ✅ 无 |
| **r20 过滤** | entry-1 与 entry-21 收盘价（入场前）| ✅ 无 |
| **TP1/TP2 目标** | entry + 1R/2R（R=entry-SL，入场前可算）或周线 BSL（入场前可见）| ✅ 无 |
| SL | zone_low/sweep_low × 0.99（入场前）| ✅ 无 |
| 出场 | entry 后实际 K 线（SL/TP 碰撞、TIME_STOP）| ✅ 无（真实发生）|

**独立验证**：oracle 覆盖 50.4%（不同实现重算身份集合一致）—— 无随机性/状态泄漏。

### 2. 事件策略（增持/回购）— ✅ 无未来

| 环节 | 使用的数据 | 是否有未来 |
|---|---|---|
| 事件识别 | 公告披露日 T（标题关键词）| ✅ 无 |
| 入场 | T+1 开盘价（披露后可得）| ✅ 无 |
| 持有期收益 | T+1 开盘 → T+10 收盘（**已发生的价格路径**）| ✅ 无 |
| 事件 oracle | 独立查询 99.3%/92.7% 身份一致 | ✅ 无 |

### 3. 组合每年收益 — ✅ 事后统计，非预测

- 回测的"每年 +2~4%"是 **2023-2026 已发生交易的统计**（历史路径上策略会赚多少）
- **不是**对未来的预测；未来表现由**纸面跟踪**（8 月新事件 → 未来 10 日观察）验证

## 二、诚实的模型风险（非未来函数，但需说明）

1. **选择偏差（参数在历史上选取）**：R20 范围（0-15%）、TP2 权重、持有期（10 日）是在**全历史上**观察后选择的。虽然做了敏感性验证（R20 0-20% 连续、持有期 5-20 日、信号分层）确认结果稳健，但**严格意义上不是预先注册的独立样本外验证**。
2. **公告数据缺口**（77% 覆盖，2025-04/05、2026-04/05 等整月缺）：事件统计基于可得数据，缺失天事件未计入 —— 平均收益无偏（缺失机制与事件独立），但**精度受限**。
3. **存活/上市偏差**：腾讯 K 线为当前在市的股票（退市股未含）—— 有轻微正偏差（退市股通常表现差）。

## 三、结论

**回测无未来函数（前置）** —— 所有信号、入场、出场均基于当时可得信息（outcome-free、PIT 严格、TP/SL 入场前可见）。

**但与"预测"的区别必须明确**：
- 回测 = 历史路径上策略的历史表现（已发生）
- 纸面跟踪 = 前瞻性验证（8 月新事件 → 未来 10 日真实观察）—— **这才是对"预测能力"的检验**
- 任何声称"未来每年 +2%"都是不成立的 —— 回测只能证明"历史上这样有效"，未来需纸面验证

**建议**：以纸面跟踪结果为唯一"前瞻性"依据；回测作为策略设计的合理性证明。
