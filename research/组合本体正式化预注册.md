# 组合本体正式化预注册（SMC 动量 + 内部人事件）

> 状态：PREREGISTRATION_FROZEN | 日期：2026-08-17
> 依据：研究闭环第三轮质变达成（2024/2025/2026 每年正收益）

## 1. 本体架构（双信号源组合）

```
信号源 A：SMC 三周期 TP2-R20（动量/结构）
  周线权限 W1 → 日线故事 D1-D4 → 日线级接管 H3 → E 入场
  过滤：r20 ∈ [0, 0.15)（温和启动）
  执行：TP2（1R 止盈 40% + runner 至 max(2R, 周线BSL) + SL 上移 BE）

信号源 B：内部人事件 M-INSIDER（事件 alpha）
  增持/回购公告披露 → 次日开盘入场 → 持有 10 日
  减持/业绩预告不参与（负/无 alpha）

组合：A + B 等权合并池（或按资金比例分配）
```

## 2. 判定标准（正式化门槛）

- **每年**（2024/2025/2026 完整年）：avg > 0、PF ≥ 1.15、WR ≥ 50%（事件拉低 WR 属预期）
- **关键**：2026 年（崩塌年）必须正（事件 alpha 补足）—— 已达成（+2.81%）
- 全市场、PIT 严格、T+1=0、outcome-free、独立 oracle
- 2023H2 与公告缺口如实标注（数据窗口）

## 3. 生产流程（scanner-time 重建）

```
每日收盘后：
1. 数据刷新（腾讯/东财全市场 K 线 + 公告）
2. SMC scanner：全市场三周期信号 + r20 过滤 → PENDING_NEXT_OPEN
3. 事件 scanner：当日增持/回购公告 → EVENT_T0 候选
4. 合并候选 → 次日开盘执行检查（open 在结构 SL/TP 内 for SMC；事件直接入场）
5. registry：候选 → BUY_VALID（生产许可后）或 RESEARCH 展示
```

## 5. 风险与边界（诚实声明）

- 2023 仅 H2 数据（-0.86%）—— 完整 2023 需数据
- 事件 alpha 依赖公告披露质量（标题级）；正文数值化是后续增强
- 2024 年 WR 49.5%（事件策略 10 日持有含弱市回撤）—— avg/PF 为正但波动大
- 组合是"多策略分散"而非"单一必胜"—— 本质是降低年景依赖
