## 二、SMC 腿（三周期 SSL sweep 链，UPTREND/MARKUP 阶段）

### 信号层（outcome-free，全部 entry 前可见）
```
1. 周线权限：受保护周线低点有效 OR 周线 SSL sweep 后向上 CHOCH（严格早于当前周）
2. D1 日线 SSL sweep：扫取可见确认 swing low ≥0.3% 且收盘收回
3. D2 日线收盘突破 sweep 时可见的最近确认 swing high（bullish CHOCH）
4. D3 从 D2 displacement leg 锚定唯一 bearish OB（zone=半 body，79% 折扣内）
5. D4 POI 首次触及（第二次触及/先跌破/收盘失效取消）
6. H3 日线收盘突破 touch 前最近确认局部 swing high（接管确认，日线代理）
7. E 下一交易日开盘入场（严格 T+1）
```

### 过滤（entry 前，PIT）
```
r20 ∈ [0, 0.15)：入场前 20 日收盘涨幅（温和启动，排除追高/深回调）
VWAP：入场价 ≥ 20 日滚动 VWAP 且偏离 ≥ 3%（趋势方向确认）
行为阶段 ∈ {UPTREND, MARKUP}：60 日滚动 ret>0（UPTREND）或 ret>0.20+量比>1.1（MARKUP）
```

### 执行（TP2 分级）
```
SL = min(zone_low, sweep_low) × 0.99（结构双低点，入场前可见）
TP1 = entry + 1×risk；命中后止盈 40% 仓位
TP2 = max(entry + 2×risk, 周线BSL)；SL 上移至 BE（保本）
max_hold = 40 根日 K；费用 0.20% 双边；T+1 严格
```

## 三、事件腿（内部人事件，ACCUM/DOWNTREND 阶段）

### 信号层（PIT 严格）
```
事件：回购预案/方案/首次实施 + 增持（标题级强信号，排除完成/进度/前十名弱信号）
入场：披露日 T → T+1 开盘（披露后可知）
行为阶段 ∈ {ACCUM, DOWNTREND}：60 日滚动 ret<0（DOWNTREND）或 ret<-0.15+量比<0.9（ACCUM）
```

### 执行（深度依赖持有）
```

非 DEEP → 持有 10 日
费用 0.20% 双边；T+1 严格；同一股票 20 日内同类事件去重
```
