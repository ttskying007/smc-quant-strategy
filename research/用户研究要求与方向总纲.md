# 用户研究要求与方向总纲（永久记忆）

> 版本：1.0 | 日期：2026-08-19
> 目的：将用户散乱表述的研究要求梳理成逻辑清晰的执行宪章。**每次研究迭代前必须检查本文档，确保方向不偏离。**

---

## 一、核心哲学（一切研究的根基）

**SMC（Smart Money Concept）策略的核心 = 大资金（聪明钱）行为痕迹**
- 系统要识别的是"大资金在做什么"，而非股票本身
- 大资金会在不同时间、不同股票上操作（同一股票 2024 和 2025 可能由不同大资金操作 = 换庄）
- **因此 DNA 追踪的是大资金行为（当前操作者），而非股票的固定属性**

## 二、策略形态要求（用户明确提出的方向）

### 1. 基础形态（大资金操作痕迹）
```
流动性扫描（sweep）→ 破了前高/前低 → 回撤到兴趣点（POI）
```
- 这是基础思路，可发散为各种类型组合

### 2. 多种类型组合（发散思维，不要死磕单一形态）
- 可以有各种类型组合（SSL sweep / BSL sweep / 双扫 / CHOCH / FVG / MSS / BOS 等）
- 可以有多个指标组合（成交量、VWAP 隧道等，具体用什么自己定义）
- 可以有不同的周期组合（月/周/日/60min）混用
- **不要在一个方向死磕，也不要随便加无关的东西** —— 以回测数据为最终标准

### 3. 个股 DNA 自动化适配（核心诉求）
```
SMC 在不同股票、不同周期大小组合、按信号发生的时间顺序，
能够根据每只股票的 DNA，进行自动化适配和最优匹配
```
- 每只股票在不同时间可能由不同大资金操作
- 策略应**按当前大资金行为自动匹配最优信号源**（行为阶段 × 趋势 × 波动率）

### 4. 辅助指标（用户点名 + 自选）
- 成交量（注意：作为诊断，不设门槛 —— 已验证无增量）
- VWAP 隧道趋势（已验证有效：价格 ≥VWAP 且偏离 ≥5%）
- **注意指标滞后性、欺骗性**（很多指标有滞后、有假信号）

## 三、研究标准（用户强调的硬性要求）

### 1. 以回测数据为最终标准
- 每年、每月的情况都要详细报告
- 不能有未来（无未来函数 / outcome-free / PIT 严格）

### 2. 每年交易胜率和盈亏比均有大幅提升
- 跨年一致（不能靠单年/单月）
- 普适性（全市场、不能有偏概率/过拟合）

### 3. 执行质量复盘（用户后加的重要要求）
- 检查是否买早了、卖早了、卖晚了
- 查看入场、出场位置的合理性
- **不要因为执行问题错判信号准确性**
- 前面几轮较好的数据表现都要检查
- 后续每轮迭代都要执行这样的检查

## 四、研究纪律（固化，每轮执行）

1. **冻结回放验证**：不信历史高指标（V88 教训：80% WR 是前视偏差）
2. **每年/每月报告**：跨年一致 + 逐月透明
3. **执行质量审计**：每轮必做（入场/出场合理性）
4. **重构完整性审查**：每轮核对旧验证是否完整继承（VWAP 曾被遗漏）
5. **集中度审计**：不追单年数字（v14 教训：2024 集中 78%）
6. **单维度微调**：不联合搜索（防过拟合）
7. **无未来函数**：PIT / outcome-free / oracle 验证
8. **前端同步**：每次任务完成后及时同步到前端展示（用户要求）
9. **扫描前确保数据最新**（用户要求）：scanner 新鲜度门控（只对最新交易日股票产生信号，stale 跳过宁缺毋错）+ 分批全市场刷新（每日600只覆盖扩大）+ 关键股票（持仓+事件）预刷新

## 五、已验证结论速查（33+ 条，防重复探索）

### 有效链
SSL sweep（唯一信号 edge）→ R20 → TP2 → VWAP ≥5% → 行为阶段 → 熊市 FVG → ADX → 深度持有 → 15 日执行

### 已验证无效（不要重复）
量能分层、共识摆动、BSL/双扫裸、CHOCH 独立、市场宽度过滤、融资融券确认、信号序列时长、zone_age、RANGE 过滤（与 FVG 等价）、业绩预告正文（限流+价值存疑）、事件结构出场（5 变体全差）

### 入场模式结论（2026-08-19 新增）
- **事件腿：突破入场（T+1 开盘）优于回撤限价**（+6.03% vs +4.94%，每年都更好）→ **事件腿不需要等回撤**（alpha 时间确认型，T+1 开始走）
- **SMC 腿：必须等回撤 POI**（结构核心，79% 折扣 OB 回撤验证过）→ SMC 腿等回撤正确
- 两种信号入场逻辑不同：事件=即时，SMC=回撤

### 反转 vs 延续方向结论（2026-08-19，用户核心方向）
- **当前策略 = 触底反弹（反转）**：SSL sweep（扫损反转）+ ACCUM/DOWNTREND 事件（底部增持）
- **趋势延续方向实测无 alpha**：
  - 事件延续（UPTREND/MARKUP 事件）：+0.41%（2024 负 -0.75%）
  - SMC 延续（UPTREND 回撤 MA20 收回）：-0.16%（n=92,787，PF 0.95）
- **反转 >> 延续（两信号都确认）**：A 股做多市场大资金 alpha 集中在**底部扫损吸筹**（反转）；趋势延续=追涨（大资金用来派发）→ 无 edge
- **结论：当前触底反弹策略是正确的市场结构方向**，趋势延续无需继续研究（与 BSL/CHOCH 无效一致）

### 排序指导（实盘资金分配）
事件 DEEP+高波动优先（Top50% = 每年 +12.5%）、SMC FVG 数量多优先
