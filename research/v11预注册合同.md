## 二、SMC 腿（三周期 SSL sweep 链）

### 信号层（outcome-free，全部 entry 前可见）
```
1. 周线权限：受保护周线低点有效 OR 周线 SSL sweep 后向上 CHOCH（严格早于当前周）
2. D1 日线 SSL sweep：扫取可见确认 swing low ≥0.3% 且收盘收回
3. D2 日线收盘突破 sweep 时可见的最近确认 swing high（bullish CHOCH）
4. D3 从 D2 displacement leg 锚定唯一 bearish OB（zone=半 body，79% 折扣内）
5. D4 POI 首次触及（第二次触及/先跌破/收盘失效取消）
6. H3 日线收盘突破 touch 前最近确认局部 swing high（接管确认，日线代理）
7. E 下一交易日开盘入场（严格 T+1）
```

### 过滤（entry 前，PIT）
```
r20 ∈ [0, 0.15)：入场前 20 日收盘涨幅（温和启动）
VWAP：入场价 ≥ 20 日滚动 VWAP 且偏离 ≥ 3%（趋势方向确认）
行为阶段 ∈ {UPTREND, MARKUP}：60 日滚动 ret>0（UPTREND）或 ret>0.20+量比>1.1（MARKUP）
【v11 新增】熊市 FVG：entry 前 12 根内出现上方供给缺口（high[k] < low[k-2]）= 抛压耗尽确认
```

### 执行（TP2 分级）
```

TP2 = max(entry + 2×risk, 周线BSL)；SL 上移 BE；max_hold 40；费用 0.20%；T+1 严格
```
