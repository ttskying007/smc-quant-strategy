# E3 预注册: min-risk_pct 入场门槛 (SL 距离下限过滤)

**创建**: 2026-09-20 · **状态**: PROPOSED (未回测/未生产)
**前置证据链**: R25 KB 规则 → R26 H4 证伪(方向反转) → R26 五档单调表 → R27 影子 A/B

## 假设
H: 在 EVENT 入场时，risk_pct(入场价到 SL 的百分比距离)低于阈值的腿系统性跑输。
**机制解释**(来自 R26 数据 + KB):
- risk_pct 窄 ⇒ SL 紧贴入场 ⇒ 正常波动即可扫损 (KB stop_loss_placement: "窄止损被扫损概率高")
- v20f 数据: 0-4.2% 档 WR=40.0% avg=+1.38%; 而 ≥16.5% 档 WR=83% avg=+5.83%

## 关键因果判断(防 look-ahead)
risk_pct 在**入场时刻由 SL 计算得出**，先于任何未来价格 → 过滤器在实盘可实施，无前视偏差。
(对照: mfe/mae 类特征是事后量，不能用于入场过滤)

## 风险与反对理由(必须正视)
1. **与 R8/v2_sl_controlled 否决实验的关系**: 那个实验是"收窄已有 SL"踩损增加;
   本提案反向(不收窄, 而是**不进入**窄 SL 的交易) — 机制不同, 但仍需警惕同族过拟合。
2. **样本期偏差**: 1527 腿主要来自 2023-10 后 转债/反向组合; 需在 OOS 窗口 + 全参数 WFO 确认。
3. **流动性解释替代假说**: risk_pct 大可能只是"波动率高的烂票", 其高收益来自波动非边缘。
   对照测试: 分档看 avg_win/avg_loss 比值是否稳定。
4. **与 rank gate 交互**: 若窄 SL 腿集中在 rank≤3, 现有 gate 已部分覆盖, 增量收益需扣除。

## 判定标准(冻结后执行)
- 样本: combo_v20f 冻结基线 + OOS 窗 (2026 年后)
- 通过条件: OOS avg 提升 ≥ +0.4pp 且 PF 不下降, 且翻转率(方向矛盾窗占比) < 40%
- 首选门槛: **4%** (影子 A/B 中 Δavg=+0.56, 剔除 292 腿为适中的交易频率代价)
- 失败即弃: 参考 D5 (flip 57% → reject) 的判定先例
