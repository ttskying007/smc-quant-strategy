## P0（生产静默失效）

### P0-1 ✅ 已修复：daily_combo_run.py 兜底模式引用未定义 KT
- **问题**：`--fallback-only` 分支 `os.listdir(KT)` 引用未定义 `KT`（文件头未定义），NameError 被 `except` 吞掉 → **08:00 补跑机制从未生效过**。
- **修复**：在兜底分支显式定义 `KT = os.path.join(ROOT, "hermes", "kline_cache_tencent")`；异常处理增加 `traceback.print_exc()` 提升可观测性。
- **验证**：`main()` 源码含 KT 定义 ✅

### P0-2 ✅ 已修复：shutil.copyfile 目标传目录
- **问题**：兜底分支 `shutil.copyfile(src, d)` 目标 `d` 是目录（`hermes/smc_monitor` 或 `E:\root\.hermes\smc_monitor`），必然 `IsADirectoryError`，被吞。
- **修复**：改为 `dst = os.path.join(d, f)`（文件路径），并 `os.makedirs(d, exist_ok=True)` + 打印同步日志。
- **验证**：编译通过 ✅

### P0-3 ✅ 已修复：账本非原子写 + load 失败返回 [] 致持仓清零
- **问题**：`save_ledger` 直接 `open(w)` 非原子写；`load_ledger` 解析失败返回 `[]`。主流程 `taskkill /F` 强杀监控若撞上写账本 → 半截 JSON → 下次加载得到 `[]` 并覆盖主文件+两个镜像 → **全部持仓静默清零**。
- **修复**：
  - 新增 `_atomic_write_json`：临时文件 + `fsync` + `os.replace`（原子替换）
  - `load_ledger`：文件不存在返回 `[]`（首次运行合法）；**文件存在但解析失败 → 抛 RuntimeError 并保留原文件**（禁止静默空账本覆盖）
  - 镜像同步失败不再静默，打印告警
- **验证**：损坏账本正确抛异常 ✅；125 条账本原子写往返一致 ✅
