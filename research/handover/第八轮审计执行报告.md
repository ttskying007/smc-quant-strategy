## 一、核心发现：`ep < 止损` 机械获利 bug（CRITICAL）

**现象**：统一事件腿过滤/退出口径到生产内核后，重跑全量回测，2024 年事件腿 avg 从 +10.9% 骤降至 +0.6%。

**根因定位**（四象限归因）：崩溃与过滤器无关，**完全来自退出逻辑差异**：
```
旧 gen_v20f 内联循环: 2024 年 n=2710 avg+11.31% WR82% PF14.03
simulate(统一内核):   2024 年 n=1302 avg+3.03%  WR61% PF2.58  ← 样本减半 + 指标下修
```
**机械获利 bug**：旧循环对 `entry_price < stop`（区间几何非法：入场价在"止损"之上）的交易，在首根K线只要 `low <= stop` 即以**高于入场价的 stop** 获利退出 —— 无论行情方向**必赢**。2024 年 2846 笔中 **1478 笔（52%）** 属此类，全部为虚假利润。

**模拟复现**：`ep=10, sl=10.2` → 旧循环首根K线 `low<=10.2` 即以 10.2 退出，稳赚 +1.8%；`simulate` 正确返回 `BAD_ENTRY` 拒绝。

## 十一、regime 闸门 A/B 验证结论（本轮，负结果 + 新认知）

**问题**（第八轮 regime 分析遗留）：弱月(Q2稳定负)是否可用市场状态信号前置闸门过滤？

**方法**：`regime_gate_ab.py` —— 用 200 股采样 20 日均涨跌重建市场 proxy（决策时点可得，无泄漏），事件腿每笔按信号日 proxy 分组 + OOS 门控验证。

**发现 1：事件腿是逆向策略（弱市表现最佳）**
```
proxy 三分位(全期间):  弱市(<q33) avg+6.60% PF6.63  ← 最佳
                      中性      avg+1.00% PF1.46
                      强市(≥q66) avg+1.34% PF1.79
```

**发现 2：正向闸门（过滤弱市）反而降低 OOS 表现**
```
基线 OOS:            avg+2.95% PF3.05
T=-0.02(滤弱市):     avg+0.89% PF1.60  ← 显著变差
T=+0.00:             avg+0.90% PF1.66
```
原因：被过滤掉的正是高收益弱市环境。

**发现 3：反向闸门（只做弱市）avg/PF 更高但绝对收益更低**
```
基线(全时段):     n=482 avg+2.95% PF3.05 总收益1420%
只做弱市<-0.02:   n=233 avg+5.15% PF4.68 总收益1199%  (-16%绝对)
只做弱市<-0.04:   n=222 avg+5.45% PF5.08 总收益1209%  (-15%绝对)
```

**结论**：
- ❌ **不启用 regime 闸门**（正向或反向）—— 全时段交易绝对收益最高，事件腿全时段为正
- ✅ **新认知：事件腿=逆向策略**，与 SMC 趋势腿(需强市)本质相反。弱市信号质量最高（avg 翻倍）
- ⏳ **建议方向**：弱市**仓位加权**（弱市加仓而非跳过）—— 需另立项验证（等权口径下加仓权重对绝对收益的影响）
