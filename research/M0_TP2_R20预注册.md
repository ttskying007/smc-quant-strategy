# 三周期 + TP2 + R20 温和上涨过滤 本体预注册（M0-TP2-R20）

> 状态：PREREGISTRATION_FROZEN | 日期：2026-08-17
> 依据：实验 E 发现 —— 三周期信号在"入场前 20 日涨幅 0~10%"子集显著更优（WR 59.8% vs 52.4%、avg +2.36% vs +0.85%、PF 1.64 vs 1.14）

## 1. 与 M0-TP2 的区别（新信号过滤语义，非调参）

| 项 | M0-TP2（基线） | M0-TP2-R20（本预注册） |
|---|---|---|
| 信号层 | 三周期状态机（W1→D1-D4→H3→E） | 同左 |
| 执行合同 | TP2（1R 止盈 + runner + BE）| 同左 |
| **新增过滤** | 无 | **入场前 20 日个股涨幅 ∈ [0%, 10%)**（温和启动，排除追高与深回调） |

**语义理由**（非数据挖掘）：
- 三周期信号本质是"结构突破后回踩确认"（continuation/reclaim）
- 个股 20 日涨幅 0~10% = 刚脱离底部/温和启动 → 结构信号最有意义（reclaim 后空间大）
- 涨幅 >10% = 已追高（假突破风险）；涨幅 <0 = 结构仍弱（sweep 后可能继续下破）
- 这是**信号有效性的结构性条件**，不是阈值微调

## 2. 冻结合同

```
信号：三周期状态机（同 M0-TP2）
过滤：entry 前 20 日收盘涨幅 r20 ∈ [0, 0.10)（r20 = close[entry-1] / close[entry-21] - 1）
执行：TP2（1R 止盈 40% + runner 至 max(2R, 周线BSL) + SL 上移 BE）
SL：min(zone_low, sweep_low)×0.99；TP1=1R；TP2=max(2R, 周线BSL)；max_hold=40；fee 0.20%；T+1 严格
```

## 3. 经济门槛（V633，冻结）

- n≥1000（或数据窗口内最大可得）、WR≥55%、AvgNet≥+0.5%、PF≥1.15、payoff≥0.70
- 每年 AvgNet>0（2024/2025/2026 数据可得年；2023 因数据窗口单独说明）
- 月度 n>4、T+1=0
