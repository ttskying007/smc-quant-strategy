# v676 三周期状态机主轴研究报告（W→D→H）

> 日期：2026-08-17 | 流水线：预注册语义 → outcome-free seed → 冻结回放 → smc_gates
> **结论先行：三周期状态机（周线权限 + 日线故事 + 日线级接管）信号质量显著优于单日线主轴（WR 68.5% vs 51.6%），验证了"周期组合"方向正确；但当前执行合同（结构 SL + 最近目标 TP）经济性不达标（小赢大亏），按预注册规则 CLOSED_NO_VARIANTS。60min 真实层因数据约束（本地仅 2025-10~2026-05）未纳入全量回测，以日线级接管代理。**

## 一、背景与数据约束

- 用户方向：信号组合、周期组合、时间顺序自动化适应、SMC 核心 —— 三周期（W→D→H）是系统 v676 章程定义的"真正的 SMC 核心"
- **60min 数据硬约束**：本地 kline_cache_60min 仅覆盖 2025-10~2026-05（500 根）；东财 60min API 上限 120 根/请求（全历史不可得）；远程已弃用不可达 → **真实 60min 层无法全量回测**，本报告用**日线级接管代理**（v676 H 层语义投影到日线）实现全量覆盖
- 数据窗口：daily_750 覆盖 2023-07-13 ~ 2026-08-14（2023 年仅下半年）

## 二、状态机实现（v676 语义，outcome-free）

```
W1  周线结构权限：受保护周线低点有效 OR 周线 SSL sweep 后向上 CHOCH（weekly 聚合自 daily，严格早于当前周）
D1  日线 SSL sweep：扫取可见确认 swing low ≥0.3% 且收盘收回
D2  日线收盘突破 sweep 时可见的最近确认 swing high（bullish CHOCH）
D3  从 D2 displacement leg 向后锚定唯一 bearish OB（zone=半 body，79% 折扣内）
D4  POI 首次触及（第二次触及/先跌破/收盘失效取消）
H3  日线收盘突破 touch 前最近确认局部 swing high（接管确认）
E   下一交易日开盘入场（严格 T+1）
SL  min(zone_low, sweep_low)×0.99（结构双低点取宽，入场前可见）
TP  周线外部 BSL 优先，日线 swing high 兜底（入场前可见）
```

## 四、核心发现

1. **周期组合方向正确（重要正面结论）**：周线权限 + 日线故事使 WR 从 51.6%（单日线）提升到 **68.5%（+17pp）** —— v676"周线负责结构权限"的语义被实证验证。2024 年完全转正（avg +1.54%、PF 1.45）
2. **执行层失败（小赢大亏）**：WR 68.5% 但 payoff 仅 0.44 —— TP 命中 70% 但平均盈利远小于平均亏损。**TP 目标（最近 swing high / 周线 BSL）相对 SL 距离不足**（RR 结构问题）：高胜率低赔率 → 期望为负
3. **2025/2026 年度转负**：与全系统一致（日线价格族 regime 依赖）
4. **2023 年样本缺失**（数据窗口 2023-07 起 + 状态机前置需求）—— 年度门槛无法完整评估

## 五、结论与纪律

- **三周期状态机作为主轴方向成立**（信号质量实证优于单日线），但**当前执行合同经济不达标**
- 按预注册规则（R5：一次冻结回放）：**M0 三周期执行合同 CLOSED_NO_VARIANTS** —— 不得在"最近目标/结构 SL"同语义上继续调阈值
- **可重新预注册的新执行合同方向**（新语义，非调参）：
  - **TP 分级**（v88 liq_then_2r_runner 思路）：目标达 1R 部分止盈、剩余 runner 跟随结构 → 改善 payoff（当前 payoff 0.44 是核心病灶）
  - 或 **RR 门槛**（v633 已含 payoff≥0.70 经济门槛；执行合同需保证 RR 结构 ≥1.5:1）
- **数据补强**（后续）：2023 全年数据（东财全量拉取需解决限流，或分片慢速拉取）+ 真实 60min（需数据源）
